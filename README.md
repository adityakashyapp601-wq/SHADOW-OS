# SHADOW OS
A futuristic hacker-inspired **educational dashboard** built with HTML, CSS and JavaScript.

## Features
- Cyber-style interface
- Browser system overview
- Public IP information lookup via ipwho.is
- Safe simulated terminal: `help`, `date`, `whoami`, `clear`, `about`
- Responsive desktop/mobile layout

## Run locally
Download/clone this repository and open `index.html` in a browser. No build tools are needed. IP lookup requires internet access.

## Safety
Educational front-end demo, not an unauthorized access tool. Use security tools only on systems you own or have permission to assess. IP location is approximate; lookup shares your public IP with the third-party provider.
